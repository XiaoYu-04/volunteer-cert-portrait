## 怎么读

文件是 **JSONL 格式**（每行一个独立 JSON 对象），是 Claude Code 的原始记录格式，
**不是给人读的文档**。要读的话：

```bash
# 看某一行的可读内容（需装 jq）
jq -r 'select(.message.content) | .message.content' 主会话-2026-09-22.jsonl | less

# 或者直接在编辑器里打开（每行一个 JSON，长行需开启自动换行）
```

> 每行包含角色、消息内容、以及**全部工具调用与返回结果**（所以体积很大）。
> 搜索关键词即可定位到当时的讨论，例如搜 `student_no` 能找到学号冲突的排查过程。

## 想看摘要而不是原始记录

原始记录很啰嗦。人读的版本在这两份文档里：

- `docs/后端进展与待办.md` —— 现状、已完成、决策理由、待办
- `docs/公益等级与标签规则方案.md` —— 公益等级与标签规则（已确认）
- `sql/README.md` —— 数据库脚本的执行方式与设计约定
- 仓库根目录 `CLAUDE.md` —— 给后续 Claude Code 会话用的项目上下文与 10 个踩过的坑

## 注意事项

- ⚠️ **这些文件包含数据库口令明文**（工具调用里有完整连接串）。本仓库是私有的，
  但**若日后转为公开，必须先删除本目录**。
- 这些是**只读存档**，不要修改。若需继续对话，用 `claude --resume` 恢复原会话，
  而不是编辑这些文件。
- Claude Code 会自动清理 `~/.claude/` 下的旧会话记录，所以本目录是长期保存的那一份。
