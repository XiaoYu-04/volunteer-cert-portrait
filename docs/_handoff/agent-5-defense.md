## ⑥ 附：本次踩到并留档的两个坑

1. **`libreoffice-kit` 直接 render PPTX 会裁掉右/下约 20%**
   实测：同一张幻灯片，直接 render 时红色标尺落在 **137.3 px/in**（应为 110），图像尺寸却按 110 算
   → 视觉上像是内容溢出到幻灯片外，**实际几何完全正常**。
   **正确做法**：`convert --input x.pptx --output x.pdf` → `render --input x.pdf`。
2. **python-pptx 的 `add_textbox` 默认带 `<a:spAutoFit/>`**
   LibreOffice 会按文字把文本框撑大而不换行，导致长文本冲出幻灯片右边界。
   修法：`tf.auto_size = MSO_AUTO_SIZE.NONE`（写 `<a:noAutofit/>`）。
   改完后实测 18/18 页 0 越界。
